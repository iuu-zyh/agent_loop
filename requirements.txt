#                 缺失 = 内芯退回 Echo 回显（对话永远复读），是最容易被误判成"mod 坏了"的故障。
#                 它自身会带入 httpx / pydantic / anyio / distro / jiter / sniffio / tqdm / typing-extensions。
#                 **上限钉在 <2 是有意的**：本机开发与全部测试跑的是 1.109.1；上游已出 3.x
#                 （依赖换成 httpx2 那一代），只确认过 `chat.completions.create` 仍在，
