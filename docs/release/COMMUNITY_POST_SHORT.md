# 八荒智能体：给《鬼谷八荒》的 NPC 接上大模型

和 NPC 说话不再从台词库里挑一句，而是由大模型当场写。他记得你们聊过什么，缺信息会自己去查，也能在游戏里真的做点事。mod 不含 AI，需要你自己准备一个大模型接口。

〔配图 1〕封面（图片：封面_1440.png）

## 和常见的 AI 对话 mod 不一样在哪

常见做法是把人物、宗门、档案、历史一次性写进提示词，每回合整段发给模型；想"做事"的时候，靠解析它输出的文字来判断意图。这里只发当下必需的局势信息（你是谁、什么关系、在哪、什么时间、在场的是谁），缺什么他自己调工具去查；做事走工具调用——模型按固定参数格式提交，服务端校验通过才执行。所以每回合发出去的内容基本固定，规模变大也不会一直为无关内容付钱。

〔配图 2〕（图片：对话.png）

## 装上之后会看到什么

**他知道你当下的处境。** 时间、你的身份与关系、在场的人、他自己的状态与近况，每次开口前自动带上；对话窗里的「运行时上下文」会把这一回合的局势列出来，只列发生变化的部分。

〔配图 3〕（图片：他看得见.png）

**他记得住。** 每句话都写进他自己的账本，带日期戳；单聊和群聊是同一份记忆——群里说过的事，单独找他聊他还记得。上下文超了会自动整理成摘要，原文不删。

〔配图 4〕（图片：每个npc的记忆是连贯的，他们记得你单独聊天的事情也记得任何群聊中的事情.png）

**他不会硬编。** 三个只读工具：翻任何人的档案（境界、关系、好感、功法、储物袋、一生经历）、全图找人、查天下大势。同名的人他会说"我分不清"，不认识就直说"不认识此人"。

**他会动手。** 六个动作工具：增减好感、结为道侣 / 拜师收徒 / 结义、召唤与传送、切磋 / 攻击 / 双修 / 论道 / 邀约 / 传功、赠予、牵线买卖、偷窃与讨要。做之前服务端会独立检查（同格、关系冲突、物资足额）；会影响你的动作大多弹确认窗，你点同意才发生，窗里的求婚词、结义词都是他现写的。

〔配图 5〕（图片：他会动手1.png）

**你能看到他怎么想的。** 内心思量逐字实时显示，行动记录写着每次工具调用的参数与结果，另有系统组装与运行时上下文。关窗他也会说完，重开窗会把整轮补演出来。

〔配图 6〕（图片：他会动手2.png）

**他有自己的性格。** 每个 NPC 可以有自己的角色卡，在设置面板的「提示词」页签里改，下一句话就生效；另有一份「自我人设」，是你写给所有 NPC 的自我介绍。

**他找上门时，不用你复述背景。** NPC 主动传讯、寻仇追杀这类原生事件窗左侧有一枚「对话」按钮，点它就把屏幕上那句原样带过去，你直接接着聊；原生选项本身的效果不受影响。

〔配图 7〕（图片：npc自动找你的时候点击左侧的ai对话按钮可以直接将背景信息传入.png）

**他也会主动找你。** 每天有一定概率主动传讯过来，屏幕角落弹一条横幅；消息存在通讯录里，点开就能聊，并标注理由（「表达思念」之类）。

〔配图 8〕（图片：主动传音.png）

**群聊里几个 NPC 一起说话。** 通讯录「群聊」页建群；每轮最多 3 个人开口，中途入群的人看不到入群前的对话，谁这一轮没能开口，屏幕上会写明原因。NPC 之间也会互相调用工具——下图是姜萌把丹药卖给了另一位 NPC。

〔配图 9〕（图片：群聊里npc之间也可以调用工具.png）

## 几点需要知道

必须自备模型接口并联网；工具调用需要模型支持，内心思量需要模型支持思维链；**记忆跟着存档走**，聊完记得存档；界面目前只有中文；打开 mod 界面时，游戏自身的 12 个大地图快捷键会被屏蔽。
