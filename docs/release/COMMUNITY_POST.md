# 八荒智能体 —— 给《鬼谷八荒》的 NPC 接上大模型

和 NPC 说话不再从游戏自带的台词里挑一句，而是由大模型当场写出来。他记得你们聊过什么，缺信息会自己去查，也能在游戏里真的做点事。

mod 本身不含 AI，需要你自己准备一个大模型接口（接口地址、API Key、模型名）；用哪家、花多少钱由你决定。

## 一、和常见的 AI 对话 mod 不一样在哪

常见的做法是：把人物、宗门、档案、历史这些资料一次性写进提示词，每回合整段发给模型；模型想"做点什么"的时候，靠解析它输出的文字（关键词、固定格式）来判断意图。

这个 mod 走的是另一条路：

- **每回合只发当下必需的信息**：你是谁、什么关系、在哪、什么时间、此刻在场的是谁。缺什么，他自己去查
- **他有一套工具**：能现场翻任何人的档案、经历、储物袋，也能查天下大事、排行榜、各地城镇宗门。查谁、查到什么程度由他判断
- **做事走工具调用**：模型按固定的参数格式提交要做什么，服务端独立校验通过才执行，而不是去猜它写的文字
- **发出去的内容基本固定**，变化只发生在真正变了的那几段——底部那行"缓存率"就是这么来的

把资料写进提示词不是错，数据量小的时候它更简单；区别主要在能查的范围、能不能动手，以及规模变大之后的开销。

他先查过天下大事，回答里的每条信息都能在同一轮的"行动记录"里找到出处。

## 二、装上之后会看到什么

下面每节都是实机截图。

### 1. 他开口之前，已经知道你当下的处境

每次说话前，这些信息会自动带上，不需要你操作：你是谁、在哪、什么境界、什么宗门；你们是什么关系、好感在哪一档、隔多远；现在是哪年哪月哪日；他自己是谁（年龄、剩余寿元、道号、境界、性格、气运、最近的经历）。

这些是"看一眼就知道"的。更细的东西——别人身上有什么、功法如何、最近天下出了什么事——他得自己调工具去查。查询是静默完成的：不弹窗、不打断你，你只会看到他回答时已经带着那些信息。

对话窗里的「运行时上下文」会把这一回合的局势一条条列出来给你看，而且只列**发生变化**的部分，没变的不重复；某一段不再适用（比如别人离开了）会标成「（已移除）」。

〔配图 3〕（图片：他看得见.png）
展开「运行时上下文」，能看到他这次拿到了什么。

### 2. 他记得住，而且单聊与群聊是同一份记忆

你们说过的每一句话都会写进他自己的账本，每句带日期戳，所以他记得"上一次见你是几个月前"。群里说过的事，之后单独找他聊，他仍然记得；你和他单独聊过的内容，他也会带进群里。

〔配图 4〕（图片：每个npc的记忆是连贯的，他们记得你单独聊天的事情也记得任何群聊中的事情.png）
这一屏里，玩家问「道友可还记得我？」——她答的是当天在群里见过的情形："自然记得。今日才见过，唐炎唐道友，散修，出手阔绰，一颗百灵石换走五千灵石坐骑的怪人——这样的人物，妾身想忘也难。"

聊久了上下文会超过模型能读的窗口。到阈值时，他会在回合边界**自动整理记忆**：久远的对话压成摘要，最近一部分保留原文。整理不会删掉原文，往上翻仍然看得到。想删掉某段对话，对话窗标题栏的「删除」可以做多选删除。

### 3. 他不会硬编：缺什么自己去查

三个只读工具给他"眼睛"：

- **查人**：任何人的档案都能翻——境界、宗门、位置、关系、好感、全部属性、功法、储物袋（每件带说明）、关系网，以及一生的经历（能按年份翻页）
- **找人**：在全图范围内按姓名、关系、境界、宗门、地区、种族、性别搜索
- **了解天下**：近期大事、排行榜（战力 / 声望 / 魅力 / 灵石）、可去的地点、宗门概览

所以问他"隔壁那个宗门最近怎么样"，他会先去查，发现情况有变再接着查，最后回你一句带着具体信息的话，而不是含糊地说"我也不太清楚"。

八荒同名的人多，查到重名他会如实说"我分不清你说的是哪个"；不认识的人就直说"我不认识此人"。查询这类工具在你忙的时候（战斗中、开着别的界面、有剧情弹窗）仍然可用，因为它们不打扰你。

### 4. 他会动手——做完之后，游戏里的世界是真的变了

七个动作工具：

- **关系**：增减好感，或者结为道侣、拜你为师、收你为徒、与你结义、认作义父母，以及解除这些关系
- **位移**：把你召唤到他身边、他传送到你身边，或者他动身前往某个城镇宗门等你
- **队伍**：邀请你或别的 NPC 同行、请离、解散队伍、查看队伍（上限 3 人）
- **行动**：切磋、攻击、双修、论道、邀约、传功；也可以自己投宗门或另寻出路（玩家只能提议）
- **赠予**：灵石、丹药、装备，可以混着送
- **买卖**：指定买卖双方、物品、数量与整笔价格，牵线做交易
- **索取**：偷你的东西，或者开口向你要

〔配图 5〕（图片：他会动手1.png）

他不乱来，有三层拦着：

- **执行前服务端会独立检查**：要不要面对面、关系状态是否冲突、货物与灵石是否足额。不通过就直接拒绝，并把原因回告给他
- **会影响你的动作大多会弹确认窗**，你点同意才会发生。窗里的求婚词、结义词、拜师词，是他按当时的情境现写的**第一人称台词**，不是预置文案
- **少数动作直接生效**，不弹窗：加 / 减好感，以及偷窃（被发现会掉好感）

有一点值得说明：**好感门槛和战力比较不在服务端校验范围内**。关系没到位该不该越界、切磋是否合适，由他按人设与剧情自己判断——所以想让某个 NPC 矜持些，得写进他的人设里。

〔配图 6〕（图片：工具触发的UI文本由模型决定，沉浸感拉满.png）
同样是"解除关系"，确认窗里的正文由模型按角色口吻写：这一屏里姜萌说的是"当初是你死皮赖脸求来的婚事，如今又是你说散就散……"

### 5. 你能看到他怎么想的

NPC 说的那句话只是结果。在那之前发生了什么，都能看见：

- **内心思量**：他回答之前的推理过程，逐字实时出现，标题上的字数还在往上跳（需要模型支持思维链）
- **行动记录**：每次工具调用一行，写着调用了哪个工具、传了什么参数、拿回什么结果。查询进行中自动展开，他一开口就自动收起；点标题随时展开
- **系统组装**：这一回合的提示词由哪些段落拼成
- **运行时上下文**：这一回合的感知数据

〔配图 7〕（图片：他会动手2.png）
这一屏是他提议切磋的完整经过：先"想"、再调用工具、拿到结果后又想了一句该怎么说，最后才开口。

底部还有一行统计，写着本轮的 token 用量、缓存率、上下文占用，以及累计的轮 / 步数。另外：你说了话就关窗去打架也没关系，这一轮照常在跑；重新打开对话窗时，mod 会把这一整轮（你发的那句话、他的思考、每一次工具调用、说到一半的正文）按原样补演出来。

### 6. 他有自己的性格

每个 NPC 都可以有自己的角色卡：配置面板的「提示词」页签里，左边选文件、右边编辑、保存，**下一句话就生效**。还有一份通用的兜底人设（没单独设置的 NPC 用它）和一份「附加规则」（拼在每个人设后面）。

列表里有一个条目叫「**自我人设（玩家）**」——你写给所有 NPC 的自我介绍：身份、来历、性情、希望被怎么称呼。默认是空的，不写就完全不注入这一段。

〔配图 8〕（图片：配置UI（提示词）.png）

### 7. 他会主动找你

每天有一定概率，跟你有交情的 NPC 会主动传讯过来，屏幕角落弹出一条横幅提醒。触发概率、冷却时间都能调，也能整个关掉；好感低于阈值的人找你找得少。

横幅只是提醒，点它不会打开对话；消息存在通讯录里，从那里点开才看得到，并且会标注理由（「表达思念」之类）。

〔配图 9〕（图片：主动传音.png）

〔配图 10〕（图片：通讯录（有未读消息会有红点）.png）
通讯录里按名字排序，显示宗门、境界、关系与好感；有新消息的人亮红点。

### 8. 他找上门的时候，不用你复述背景

NPC 主动找你、寻仇追杀这类原生剧情 / 事件窗里，屏幕左侧会多出一枚「**对话**」按钮：

〔配图 11〕（图片：npc自动找你的时候点击左侧的ai对话按钮可以直接将背景信息传入.png）
这一屏是公冶抚找上门来，屏幕上他说的是"我正道斩妖除魔，惩奸除恶！维护着八荒中的和平与秩序。"，左下角那枚「对话」按钮是 mod 加的。

点它之后，mod 会把**屏幕上那句话原样**交给模型——取的就是界面上显示的成品句，不做推断——他按自己的人设接住这个话头，你直接接着聊就行，不用再自己复述一遍"刚才谁找我说了什么"：

〔配图 12〕（图片：npc自动找你的时候点击左侧的ai对话按钮可以直接将背景信息传入，再也不用手动手输入背景信息啦.png）
点完按钮进到对话窗：气泡上标着「—— 主动传音 ——」，他接着刚才那件事说下去（"唐道友，久违了。这一句并非虚言——我丹阳谷弟子行走八荒，斩妖除魔、护佑黎民……"）。

几点说明：

- 这枚按钮**不改变原生剧情**：原来的选项、结算照旧，被寻仇时该打起来还是会打起来，它只是多开一个入口
- 语义是**中性**的：同一枚按钮既服务"他主动找上门"，也服务"你点了闲聊"——只把交互内容交给模型，不预设是谁主动
- 没有 NPC 的系统公告类剧情不会出现这枚按钮

### 9. 群聊：几个 NPC 一起说话

在通讯录的「群聊」页可以建群、拉人、删除群聊；群窗标题栏有「拉人」「踢人」「删除」「设置」。

〔配图 13〕（图片：通讯录里支持群聊新建与删除.png）

群里的规则和单聊不太一样：

- 你发一句之后，房间按顺序点名成员回应，**每轮最多 3 个人开口**——人多的群不会每轮所有人都跑一遍，不说话的旁听者不消耗 token
- 被点名不等于必须说话，他可以选择不说话
- 每个成员有自己的上下文与账本；群里的发言按各自的位置增量投递给他。**中途入群的人看不到入群前的对话**
- 群聊里不显示「系统组装」和「运行时上下文」（每个成员各一套太乱），只保留「内心思量」和「行动记录」，标题上带说话人的名字
- 某个成员这一轮没能开口（模型超时或出错）时，屏幕上会写明，例如「姜萌 这次没能开口：模型一直没开口（首字超时），本轮跳过」，而不是让她的气泡悄悄消失

〔配图 14〕（图片：群聊图1.png）
玩家只说了一句「你们好」，两个 NPC 各自回应；姜萌先跟身旁不认识的女子打了个招呼、互报宗门，然后才回头问玩家"唐郎，你这位朋友倒是个生面孔"。

〔配图 15〕（图片：群聊图2.png）
群里接着聊：他们能看到彼此说过的话，也会互相接话。

NPC 之间也能互相调用工具。下面这屏里，姜萌把「六品化瘀丹」×5 卖给了濮阳彤萱，价 120 灵石——行动记录里写着工具参数、结算明细，以及双方灵石与物品数量的前后变化（姜萌灵石 142→262，濮阳彤萱 1485→1365）：

## 三、几点需要知道

- 必须自备模型接口，mod 不含 AI，也没有内置额度；除非在本地跑模型，否则需要联网
- 工具调用需要模型支持；「内心思量」需要模型支持思维链。不支持的模型只是少了这些部分，聊天本身不受影响
- **记忆跟着存档走**：只有游戏内存档才会把对话写进去。聊完不存档直接退出，这段对话不算数；读档会回到存档那一刻
- 界面目前只有中文；AI 回复需要几秒钟，快慢取决于模型与网络
- 打开 mod 的界面时，游戏自身的 12 个大地图快捷键会被屏蔽（避免打字时误触），ESC 与鼠标点击不受影响；mod 自身没有任何快捷键
- mod 只读游戏数据，不写游戏存档；对话记录存在你自己电脑上，除了你填的那个模型服务，不会发给别人
