## 0. 流程与通用约束（出图后按此验收）

* **流程**：出图 → 透明底处理 → 放 `ui_preview/Assets/art/<面板名>/` → 导入 **Texture Type = Sprite (2D and UI)** → 换预制件（`Assets/Resources/UI/UIChatAi.prefab` / `UIConfigAi.prefab` / `UIContactAi.prefab`）对应节点的 Image → 重打 AB。**节点名不变就无需改代码**；图与预制体**同包**打包（先例 `panel_bg.png.png` 与 UIChatAi 同 bundle）。
* **透明背景 PNG**（工具不出透明底就按白底出、后期抠图；卡片投影是半透明灰，用**图层蒙版**别硬擦）；**严禁**文字、水印、logo、边框描线、暗色调、高饱和、人脸五官细节（头像只要剪影）；**尺寸按 2x 出图**；英文工具直译即可，但**"中心纯色 / 透明背景 / 无文字"三条务必保留**；同一批图同一工具/模型/时段生成，一套 UI 不混用两种锚点。
* **九宫格类（卡片/气泡/胶囊/凹槽/按钮/行底）**：画面**中心区域必须均匀纯色**——无渐变、无纹理、无图案、无明暗变化（否则 9-slice 拉伸会花），圆角与装饰只允许出现在四角与边缘。
* **全幅类（面板背景）**：尺寸固定、按 `Image.Type.Simple` 满幅贴，四角做圆角透明。

## 3. 微信风格对话 UI（另一套布局规范，与 1/2 不同族）

| 元素 | 色值/规格 |
|---|---|
| 对话背景 | 纯色 `#EDEDED`（无需生图，UGUI 纯色 Image 即可） |
| 对方气泡 | 纯白 `#FFFFFF`，圆角 ~10px，**左上角**小三角尾巴指向头像（带一圈极淡浅灰 `#E0E0E0` 细描边以便在浅灰背景上显出轮廓） |
| 用户气泡 | 微信绿 `#95EC69`，圆角 ~10px，**右上角**小三角尾巴指向头像 |
| 气泡文字 | 近黑 `#191919`（两侧气泡都是黑字），正文 17px 左右 |
| 气泡最大宽度 | 约屏宽/面板宽 65~70% |
| 头像 | 48px 圆角方形（圆角 ~4px），随气泡走：NPC 左、玩家右 |
| 时间戳/系统行 | `#B2B2B2`，居中小字 |
| 输入栏 | 背景条 `#F7F7F7` + 顶部 1px `#E0E0E0` 分隔线 |
| 输入框 | 白色 `#FFFFFF` 圆角矩形（圆角 ~8px），占位字 `#B2B2B2` |
| 发送按钮 | 微信绿 `#07C160` 圆角矩形（圆角 ~6px），白字"发送" |

* **单素材四项**（建议一张一条生成，**不要四件套拼一张图**——拆不开）：
  **用户气泡** `#95EC69`、圆角约 12px、右上角实心小三角尾巴、纯色无描边无阴影、约占画面宽 60%、居中放纯白底；
  **对方气泡** `#FFFFFF`、圆角约 12px、左上角实心小三角尾巴、极淡 `#E0E0E0` 细描边、居中放纯浅灰 `#EDEDED` 底；
  **底部输入栏** 横向长条贴满画面宽、`#F7F7F7` 底 + 顶边 1px `#E0E0E0`、左侧白色圆角输入框约 70% 宽、右侧 `#07C160` 圆角按钮、内部全空白；
  **对话背景** 纯色 `#EDEDED`（不需生图）。
  已出图样张在 `generated-images/`（整体效果图 + 绿/白气泡各一张）。
* **古风变体**（微信布局 + 宣纸材质）：圆角矩形气泡、米白宣纸质感底色（接近 `#FFFFFF`）、边缘极轻微不规则纸边、纸面极淡水墨纹理、左上角同材质小三角尾巴（绿色版换成"带宣纸纹理的浅绿 `#95EC69`"，尾巴在右上角）。
* **落地小贴士**：① 生图 AI 基本出不了真透明 PNG——选纯色底生成后抠图；② **色值不会精确**，别抠图片色值，直接在 UGUI `Image.color` 上覆写标准色值对齐；③ 九宫格 border 设在圆角内侧、**不含尾巴区域**（尾巴在角上会被拉伸变形）——更稳是让 AI 只生成"无尾巴纯圆角矩形"，尾巴单独出一小块正三角图在预制件里叠在气泡角上；④ **文字一律引擎渲染**；⑤ 纯色圆角矩形 + 三角形用代码或绘图工具几秒可画到像素级精确，AI 生图的价值主要在"要材质质感"的场景；⑥ 映射到本面板：聊天区背景换 `#EDEDED`；NPC 行 = 左侧 48px 圆角方头像（`PortraitService` 出图缩放）+ 白色气泡；玩家行 = 右侧绿气泡 + 头像；大立绘可保留在面板顶部当"角色卡"；输入栏贴底；时间戳/系统行/折叠行用居中灰字样式。

## 4. 出图后的接入步骤

1. **放置**：`ui_preview/Assets/art/contact/`（对话/配置同理各建 `art/chat/`、`art/config/`），导入 Texture Type = Sprite (2D and UI)。
2. **替换**：卡片/气泡/胶囊/凹槽/按钮/行底 → `Image Type = Sliced`（绿色虚线圈住圆角 + 阴影，中心必须落在纯色区）；圆形按钮/头像/图标/面板背景 → `Simple`；原节点 Color 多为白色乘色，保持白色（个别带色的改回白色）；换掉 `btn_confirm` 整图后可删行内 `ChatBtn/Icon` 子文字，换掉卡片后 `ContactItem` 根上的投影 Image 可清空（投影已烘焙进卡图）。
3. **重打 AB**：`ABBuildRunner.cs` 把新图与预制体登记进同一 bundle（参照既有 `BgPath = "Assets/art/panel_bg.png.png"` 写法加条目），构建后拷 `ModRes\AssetBundle\ab\ui\`；`ui_preview` 场景预览查清晰度与九宫格拉花（重点：卡片拉到最宽长名字/最窄时边缘），并与实际面板截图对色。打包链细节见 [`APPENDIX.md`](APPENDIX.md) §E.2。
4. **代码版兜底面板**（可选，不属生图范围）：颜色常量集中在 `ConfigUiBuilder` 顶部（`CtrlBg`/`CtrlBgActive`/`PanelBg` 等同族常量），改这几个常量即可让无 AB 的兜底面板也变浅色。
