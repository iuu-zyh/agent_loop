八荒智能体

给《鬼谷八荒》的 NPC 接上大模型：有记忆、有性格，能查资料，也能在游戏里做事。

免费发布在 Steam 创意工坊；源码公开在 GitHub：https://github.com/iuu-zyh/agent_loop

——————————————————
一、这是什么
——————————

和 NPC 说话不再从游戏自带台词里挑，而是由大模型当场写出来。

每次开口前自动带上：你是谁、在哪、什么境界、什么宗门；你们什么关系、好感哪档、隔多远；现在哪年哪月；他自己是谁（年龄、寿元、道号、境界、性格、气运、近况）。

更细的信息他自己查：对方身上有什么、功法如何、天下出了什么事。查谁、查到多深由他判断；查询静默完成，不弹窗、不打断你。一回合可连续决策好几步。

他记得你们聊过什么：单聊和群聊共用一份记忆。

与常见 AI 对话 mod 的区别：常见做法每回合重发一大段档案、靠解析文字猜意图；这里只发必需的局势，缺什么现查，动作走工具调用并校验。

mod 本体负责界面与操作，AgentLoopServer.exe 管对话、工具、记忆与压缩（随 mod 附带，不用装 Python），大模型接口自己准备。

——————————————————
二、配置大模型（第一次必做）
——————————

不填 API Key 时 NPC 只会复读你的话。准备接口地址、API Key、模型名，可买官方 API、用中转，或本地跑 Ollama。

打开任意对话窗 → 右上角「设置」→「大模型」页 → 填入三项 →「测试连接」→「保存大模型设置」。

· 测试连接真发一次请求：通了显示「连接正常（3514ms）」，没通会说清是地址、Key 还是请求头。
· base_url 填到 /v1，例如 https://api.deepseek.com/v1，不要加 /chat/completions。
· 想让他看图：打开「多模态」，再粘贴图片；需模型支持图片输入。
· 保存后多数设置即时生效，只有「WS 端口」要重启；也可编辑 %USERPROFILE%\.agent_loop\config.json 后重启。

建议用支持工具调用的模型；支持思维链还能看到「内心思量」。需自备接口并联网，界面只有中文。

——————————————————
三、怎么开始聊
——————————

三个入口：NPC 信息面板「对话」；大地图 HUD「传」打开通讯录点一行；原生对话 / 剧情窗「对话」——会把屏幕那句原样带过去，原生选项不受影响。

通讯录分「好友」「最近」「群聊」，显示头像，新消息亮红点。加好友在 NPC 信息面板，与「对话」同列。

他也会主动找你：每天有一定概率传讯，角落弹横幅。横幅只是提醒，消息在通讯录，点开就能聊，并标注理由。

——————————————————
四、群聊
——————————

通讯录「群聊」页 →「+ 新建群聊」→ 勾选成员 → 确认；点列表那行开窗。右上角「拉人」「踢人」「删除」「设置」。

· 拉人：候选是没进群的好友；新人看不到入群前的对话，之后每句都收到。
· 踢人：两段确认；被移出的人记得旧事，之后群消息不再给他。
· 删除群聊在「群聊」页底部，可多选、两段确认、不可恢复——删的只是群，成员记忆还在。
· 群窗 ✕ 是「离开群聊」，记录保留，从通讯录点回接着聊。

你发一句，按顺序点名成员回应，每轮最多 3 人开口，被点到的也可以不说。谁没能开口（超时或出错），屏幕会写明是谁、什么原因。

——————————————————
五、十个工具
——————————

只读三个（你忙时也能用）：查某人完整档案（境界、宗门、关系、好感、功法、储物袋、一生经历）；全图找人；天下大势。

动作七个（会真改游戏状态）：增加好感、结为道侣或夫妻、拜师收徒、结义、认义父母、捎话及解除；召唤、传送、动身去某地等你；邀请同行、请离或散队、查看队伍（上限 3 人）；切磋、攻击、双修、论道、邀约、传功；劝他投宗门或另寻出路；赠送灵石丹药装备；牵线买卖；偷窃与讨要。你忙时会被拦下。

· 影响你的动作大多弹确认窗，点了同意才发生；窗里求婚词、结义词是他现写的第一人称台词。
· 直接生效的少数：加减好感，以及偷窃（被发现掉好感）。
· 执行前服务端独立检查：是否面对面、关系是否冲突、货物灵石是否足额；好感门槛与战力不校验，由他按人设和剧情判断。

六、过程可见
——————————

· 内心思量：回答前的推理，逐字实时显示（需模型支持思维链）。
· 行动记录：每次工具调用一行：调什么、传什么、拿回什么。
· 系统组装：这回合提示词由哪些段落拼成。
· 运行时上下文：这回合感知数据，只列变化的部分。

底部统计本轮 token、缓存率、上下文占用与累计轮 / 步数。关窗不影响，这一轮跑完后重开窗会补演整轮。

对话窗可拖动并记住位置；打开只加载最近一段，往上滚自动取更早的。

——————————————————
七、记忆、存档与卸载
——————————

· 对话记录在 C:\Users\<你的用户名>\.sessions\，按存档分目录，每个 NPC 一份，群聊也在里面。
· 设置、提示词、自建人设、日志在 %USERPROFILE%\.agent_loop\，不在 mod 内，更新不覆盖。
· 只有游戏内存档才写入：聊完不存档就退，这段不算数；读档回到存档那一刻。
· 想忘掉某人：标题栏「删除」进删除模式，多选后两段确认；或直接删文件。
· 彻底卸载：删掉 mod 文件夹、.sessions 与 .agent_loop，以及 %TEMP%\agent_loop_clip\。
· 换台机器：把 .sessions 和 .agent_loop 拷过去，再带游戏存档。
