八荒智能体

给《鬼谷八荒》的 NPC 接上大模型：他们有记忆、有性格，能查资料，也能在游戏里做事。

——————————————————
一、这是什么
——————————

和 NPC 说话不再从游戏自带台词里挑一句，而是由大模型当场写出来。

每次开口前，这些信息会自动带上，不需要你操作：你是谁、在哪、什么境界、什么宗门；你们什么关系、好感在哪一档、隔多远；现在哪年哪月；他自己是谁（年龄、寿元、道号、境界、性格、气运、近况）。

需要更细的信息，他自己调工具去查：对方身上有什么、功法如何、天下最近出了什么事。查谁、查到什么程度由他判断；查询静默完成，不弹窗、不打断你。一个回合里他可以连续决策好几步。

他记得你们聊过什么：单聊和群聊共用同一份记忆。

· 和常见的 AI 对话 mod 有什么区别

常见做法是把人物、宗门、档案、历史一次性写进提示词，每回合整段发给模型；模型想"做点什么"时，靠解析它输出的文字来判断意图。区别在四点：

1. 发的内容：前者每回合重发那一大段；这里只发当下必需的局势信息，缺什么它自己去查。
2. 能答的范围：前者取决于一开始塞了多少；这里全图任何人的档案、经历、储物袋，以及天下大事、排行榜、城镇宗门都能现场查。
3. 能不能做事：前者靠解析文字猜意图，格式一跑偏动作就丢了；这里走工具调用，模型按固定参数格式提交，服务端校验通过才执行。
4. 开销：资料越多提示词越长、为无关内容付的钱越多，内容一变缓存就作废；这里每回合发的内容基本固定。

两种做法各有适用场景，这里讲的是机制上的区别。

这个 mod 不含 AI，由三部分组成：mod 本体（游戏内界面与操作）、AgentLoopServer.exe（对话、工具、记忆与压缩，随 mod 附带，不用装 Python）、大模型接口（自己准备）。mod 免费。

——————————————————
二、配置大模型（第一次必做）
——————————

不填 API Key 时，NPC 只会复读你说的话。先准备三样：接口地址、API Key、模型名 —— 可以买厂商的官方 API、用中转服务，或在本地跑 Ollama。

在游戏里填：打开任意一个对话窗 → 右上角「设置」→「大模型」页 → 填入三项 →「测试连接」→「保存大模型设置」。

· 测试连接会真发一次请求：通了显示「连接正常（3514ms）」，没通会说明是地址、Key 还是网关要求自定义请求头。
· base_url 填到 /v1 为止，例如 https://api.deepseek.com/v1，不要再加 /chat/completions。
· 保存后绝大部分设置即时生效，只有「WS 端口」需要重启；也可以直接编辑 ModAssets\config.json 后重启游戏。

建议用支持工具调用的模型（不支持就只能聊天）；支持思维链的还能看到「内心思量」。mod 不含 AI，需自备接口并联网，界面只有中文。

——————————————————
三、怎么开始聊
——————————

三个入口，用哪个都行：

· 遇到 NPC：打开他的信息面板，点左侧「对话」，当前对话的背景会一起带过去。
· 主动找人：点大地图 HUD 上的「传」按钮打开通讯录，点其中一行。
· 游戏原生对话 / 剧情窗（包括 NPC 主动传讯、寻仇追杀找上门）左侧的「对话」按钮：会把他屏幕上刚说的那句原样带过去，不用你自己复述背景；原生选项本身的效果不受影响。

他也会主动找你：每天有一定概率主动传讯过来，屏幕角落弹一条横幅。横幅只是提醒，消息在通讯录里，点开就能聊，并且会标注理由（「表达思念」之类）。

——————————————————
四、群聊
——————————

通讯录切到「群聊」页 →「+ 新建群聊」→ 勾选成员 → 确认；建好后点列表那一行打开群窗。群窗右上角有「拉人」「踢人」「删除」「设置」：

· 拉人：候选是还没进群的好友；新加入的成员看不到入群前的对话，之后的每句话都会收到。
· 踢人：两段确认；被移出的人记得之前聊过的事，但之后的群消息不再发给他。
· 删除群聊在通讯录「群聊」页底部，可多选、两段确认、不可恢复 —— 删的只是群，成员各自的记忆还在。
· 群窗的 ✕ 是「离开群聊」，记录保留，从通讯录点回来就能接着聊。

群里你发一句，按顺序点名成员回应，每轮最多 3 个人开口，被点到的人也可以不说话。谁这一轮没能开口（超时或出错），屏幕上会写明是谁、什么原因。

——————————————————
五、九个工具
——————————

只读三个（你忙时也能用，查询不打断你）：查某人的完整档案（境界、宗门、关系、好感、功法、储物袋、一生经历）；全图找人；了解天下大势。

动作六个（真的改变游戏状态）：增减好感、结为道侣、拜师收徒、结义、解除关系；召唤、传送、动身去某地等你；切磋、攻击、双修、论道、邀约、传功；赠予灵石丹药装备；牵线买卖；偷窃与讨要。你忙时这六个会被拦下。

· 会影响你的动作大多会弹确认窗，你点同意才会发生；窗里的求婚词、结义词是他按情境现写的第一人称台词。
· 少数动作直接生效：加 / 减好感，以及偷窃（被发现会掉好感）。
· 执行前服务端会独立检查：要不要面对面、关系是否冲突、货物与灵石是否足额；好感门槛与战力不校验，由他按人设和剧情判断。

——————————————————
六、过程可见
——————————

· 内心思量：回答前的推理过程，逐字实时显示（需要模型支持思维链）。
· 行动记录：每次工具调用一行：调了什么、传了什么参数、拿回什么结果。
· 系统组装：这一回合的提示词由哪些段落拼成。
· 运行时上下文：这一回合的感知数据，只列发生变化的部分。

底部还有一行统计：本轮 token 用量、缓存率、上下文占用与累计轮 / 步数。说了话就关窗也没关系，这一轮照常在跑；重开窗会把整轮（你的话、他的思考、每次工具调用、半截正文）补演出来。

——————————————————
七、记忆、存档与卸载
——————————

· 对话记录在 C:\Users\<你的用户名>\.sessions\ 里，按存档分目录，每个 NPC 一份文件，群聊记录也在里面。
· 只有游戏内存档才会写进去：聊完不存档直接退出游戏，这段对话不算数；读档会回到存档那一刻。
· 想忘掉某个人的对话：对话窗标题栏的「删除」进入删除模式，多选后两段确认；或直接删对应文件。
· 彻底卸载：删掉 mod 文件夹与 .sessions 目录。通讯录名单是立即保存的，不受存档影响。
