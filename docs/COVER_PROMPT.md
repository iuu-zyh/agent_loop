# 工坊封面设计概要 —— 《八荒智能体》

## 一、核心创意：把「智能体」翻译成仙侠的语言

工坊封面要一眼说出：**这个人有脑子，他在感知、在思考、在行动。**

硬画机器人、数据流、赛博霓虹 —— 和《鬼谷八荒》的水墨世界完全不搭，一眼廉价。

最好的办法是找一个**仙侠里本来就有的概念**，和 AI agent 严丝合缝地重合。它就是 —— **神识**。

> 修仙者以神识探查天地万物。这本来就是 agent 的"感知世界"。

所以封面的主视觉是：

> **一个 NPC，从他的识海展开一张金色的神识网络，网上连着他"看见"的一切。**

这个隐喻同时干掉了三件事：贴游戏世界观、说清"感知"、而且够神秘好看。

---

## 二、构图（照着这个描述去生成）

### 主体

画面中央偏右，一位中国古代修仙者的**半身像**。建议男性剑修（长发束冠、青灰色道袍、肩背一柄古剑），因为他微微侧头、目光望向画面左上方的姿态，最能表现"他在看别人看不见的东西"。

神情要**沉静、专注、若有所思** —— 不要凶，不要笑。

### 核心视觉：识海法阵

从他**脑后（识海处）**向外展开一轮巨大的、半透明的**金色法阵**：

- 由层层**同心圆环**构成，像罗盘，也像星图
- 环上密布**细小的古篆符文**
- 环与环之间有**细线相连**，像星图，也像神经网络 —— 这是"智能"的视觉信号
- 法阵**正中心有一点极亮的光** —— 那是他的"核心"

### 延伸：他能触及的一切

法阵边缘射出数条**细细的金色光线**，通向四周虚空。每条光线末端悬着一个微小的物象：

- 一柄剑
- 一枚丹药
- 远山中的一座山门
- 一个模糊的人影剪影
- 一卷书

其中 **两三条光线特别亮**，光线上有**流动的光点**在移动 —— 暗示"他正在调用某个工具"。

### 背景

虚化的八荒山水：远山层叠、云雾缭绕、水墨渲染、整体压暗。以青绿与墨色为主，铺在宣纸的米黄底色上。

### 色调与光影

| | |
|---|---|
| 主色 | 青绿、墨黑、宣纸米黄 |
| 高光 | **金色，且只用金色做高光** |
| 光源 | 法阵自发光，从背后打在人物侧脸与道袍边缘（勾出轮廓光） |
| 风格 | 新中式水墨 + 仙侠插画，细腻有质感，电影感构图 |

## 四、关于标题文字

标题「**八荒智能体**」已经写进上面的提示词里，让模型一起生成。现在的主流生图模型（即梦、可灵、GPT-4o、Nano Banana、Seedream 等）写中文已经相当可靠，一次出对的概率不低。

**但要检查两件事**：

1. **笔画对不对** —— 生成后放大看「荒」「智」这两个笔画多的字，有没有多笔少笔。错了就重抽。
2. **位置别挡住主体** —— 标题压在人脸上或者压在法阵中心就废了。

如果抽了几次字还是不理想，再退回后期加字。生成时就把左下角留成暗色空区，方便叠字：

| 元素 | 内容 | 建议 |
|---|---|---|
| 主标题 | **八荒智能体** | 书法体或篆刻风，字号要大，金色描边 + 深色投影 |
| 副标题 | `感知世界 · 按需调用工具 · 长期记忆 · 性格自定` | 小字，白色或浅金，主标题下方一行 |
| 角标（可选） | `AI 驱动` | 做个小徽章放角落 |

**缩略图测试**：把图缩到 200px 宽看一眼。如果还认得出"一个人 + 一个发光的环 + 五个字"，就合格了。封面在工坊列表里就是这么小。

## 五、备选方案（如果主方案不满意）

**A ｜ 识海之中** —— 更抽象高级
特写 NPC 的头肩，**闭眼**，眉心一点金光。头部周围浮现出半透明的、由金色符文构成的思想脉络，像水中晕开的水墨。
优点：高级、聚焦。缺点：缩略图上看不出"智能体"，比较像普通修仙插画。

**B ｜ 九器环绕** —— 更强调"会动手"
NPC 居中站立，周围**悬浮九个发光的器物/符号**，代表九个工具（剑、丹药、书卷、山门、钱币、人影、印玺、罗盘、锁）。
优点：信息量大。缺点：九件东西缩小后糊成一团，缩略图会乱。

**C ｜ 一问一世界** —— 强调对话
两个修仙者相对而立，中间悬浮一张发光的传音法阵，法阵上浮现出正在流动的文字。
优点：直观。缺点：太像"聊天"，agent 的特质没出来。

> **推荐主方案**。它在缩略图尺寸下的辨识度最高，而且"人 + 发光法阵"这个组合既有仙侠感又有智能感，是四个方案里唯一一个**一眼就知道这不只是普通对话 mod** 的。
