# 发布到创意工坊 —— 操作说明

## ⚠️ 先搞清楚一件事：工坊页面不是 Markdown

`WORKSHOP_PAGE.txt` 是**纯文本**草稿；Steam 创意工坊的描述框不支持纯文本排版，它用的是 **BBCode** —— 一套完全不同的语法。

如果直接把 md 粘进去，你会看到满屏的 `##`、`**`、`---` 原样显示出来，非常难看。

| | Markdown（我写的） | BBCode（工坊要的） |
|---|---|---|
| 标题 | `## 一、他是什么样的` | `[h2]一、他是什么样的[/h2]` |
| 加粗 | `**看得见**` | `[b]看得见[/b]` |
| 图片 | `![图](a.png)` | `[img]图片网址[/img]` |
| 分割线 | `---` | `[hr][/hr]` |
| 列表 | `- 项目` | `[list][*]项目[/list]` |

**好消息**：我已经帮你转好了 —— 见 `docs/WORKSHOP_PAGE_BBCODE.txt`，可以直接整段复制粘贴。

---

## 一、工坊页面的内容是从哪来的

一个工坊物品页面由**三块**内容拼成，来源各不相同：

| 页面上的部分 | 从哪来 |
|---|---|
| **标题、标签、预览图** | 从**游戏内的模组编辑器**上传时填写 |
| **简介（短描述）** | 编辑器里的「描述」字段 |
| **详细描述（长文 + 图片）** | **发布后，在 Steam 网页上编辑** |

关键点：**长文和图片是在网页上编辑的**，不是在编辑器里。编辑器里的描述框只有一行，放不下我们这篇长文。

---

## 二、上传流程

编辑器是**游戏内**的，不是独立 exe（游戏根目录下没有编辑器程序）。

### 第一步：在编辑器里补全信息

打开游戏 → 主菜单进「**制作模组**」→ 打开你的工程 `ModProject_Jgmg5L` → 点右下角「**编辑**」。

然后填这几项（这些字段都存在 `ModProject.cache` 里，就是编辑器要收集的东西）：

| 字段 | 当前值 | 要改成 |
|---|---|---|
| `name` | `模组Jgmg5L` | **八荒智能体** |
| `desc` | `创建时间2026_09_01_11_42_10` | 一句话简介（见下） |
| `author` | `iuuuuuu` | 确认无误 |
| `ver` | `v 1.0.0` | 确认无误 |
| `addPreviewPaths` | `["","","","",""]` | **填 5 张预览图**（见第四节） |
| `tags` | `[]` | 加标签，至少 `修仙`、`功能`、`AI` |
| `visibleState` | `0` | 公开 |

**`desc` 字段建议**（编辑器里那个「描述」框，先用纯文本，别放 BBCode —— 不确定它解不解析标记）：

```
八荒里的每一个人，都有自己的脑子。

《八荒智能体》把《鬼谷八荒》的 NPC 交给真正的 AI 智能体驱动。

他看得见你的处境——境界、宗门、声名、容貌、心境，你们隔多远、是什么关系、
好感几何，以及现在是哪年哪月。他记得住你们之间发生过的一切，聊得再久也会
自己整理记忆。他按需调用工具，而不是把整个世界塞进提示词，所以不慢；对话
只往后追加、能吃到前缀缓存，所以越聊越省。

而且他不只会说话——结为道侣、拜你为师、收你为徒、与你结义、赠你丹药灵石、
与你做买卖，也会主动约你切磋、论道、双修、传功，甚至偷你的东西。这些不是
台词，是游戏里真实的关系与物品变更。

最特别的是：他思考与行动的全过程，你都看得见。

需自备一个 OpenAI 兼容的模型接口（游戏内按 F11 填写，自带「测试连接」帮你排错）。
```

发布后再到网页上「编辑标题和描述」，换成 `WORKSHOP_PAGE_BBCODE.txt` 那份带图完整版。

### 第二步：导出

编辑器里点「**保存**」→「**导出模组**」。导出的东西会进 `ModExportData/Mod_Jgmg5L/`。

### 第三步：本机验证（强烈建议）

回到游戏 →「**本地模组**」→「**导入模组数据**」→ 选中导出的 `Mod_Jgmg5L` 目录 → 显示「已导入」就成功了。

**这一步必须在发布前做。** 它验证的是导出的包本身没问题 —— 和你平时跑开发模式是两条路径。

### 第四步：上传

在模组编辑器里找**上传 / 发布**入口（通常在右上角或菜单里）。第一次上传 Steam 会要求邮箱验证，之后需要等审核。

> ⚠️ 我没有实际点过这个按钮，无法给你逐帧的按钮位置。**你打开编辑器截图给我，我把每一步的按钮名写准。**

## 三、详细描述怎么填

发布成功后：

1. 打开你的工坊物品页面
2. 点右侧的「**编辑标题和描述**」
3. 把 `docs/WORKSHOP_PAGE_BBCODE.txt` 的内容**整段粘进去**
4. 保存

这个编辑器是 BBCode 的，粘贴后可以点「预览」确认排版。

### 支持的 BBCode 标签

```
[h1]…[/h1]  [h2]…[/h2]  [h3]…[/h3]     ← 只有三级标题
[b]粗体[/b]  [u]下划线[/u]  [i]斜体[/i]  [strike]删除线[/strike]
[url=网址]链接文字[/url]
[img]图片网址[/img]                      ← 图片必须是外链
[list][*]项目[/list]      [olist][*]项目[/olist]
[quote]引用[/quote]  [code]代码[/code]  [hr][/hr]
[table][tr][th]表头[/th][/tr][tr][td]单元格[/td][/tr][/table]
```

**没有四级标题**，所以我的 md 里如果有更深的层级，转换时会降级处理。

## 四、图片是最大的坑

`[img]` **只接受外链网址**，不能是本地文件。而且 Steam 的描述编辑器**没有上传图片的按钮**。

所以那 9 张截图，得先有个地方放。

### 方案 A：用 Steam 自己的图床（推荐）

Steam 社区本身就能托管图片，而且在国区访问稳定：

1. 进《鬼谷八荒》社区中心 →「**截图**」或「**艺术作品**」
2. 上传你的截图，设为**公开**
3. 打开这张图 → 右键「**复制图片地址**」
4. 得到形如 `https://images.steamusercontent.com/ugc/....png` 的直链
5. 填进 BBCode 的 `[img]这里[/img]`

**优点**：不依赖第三方图床，不会被墙，不会过期。

### 方案 B：第三方图床

imgur 之类在国内打不开，**不推荐**。如果要用，选国内可访问的图床，但存在失效风险。

### 五张预览图（`addPreviewPaths`）不用外链

那 5 张是编辑器直接读本地文件上传的，走的是 Steam 工坊的预览图通道，**和描述里的 `[img]` 是两回事**。

建议分配：

| 槽位 | 放什么 |
|---|---|
| 1 | 封面（AI 生成的那张） |
| 2 | `他会动手2.png` —— 完整智能体循环 |
| 3 | `主动传音2.png` —— 最有感染力 |
| 4 | `全程可见.png` —— 运行时上下文逐条可见 |
| 5 | `通讯录.png` 或 `主动传音.png` |

## 五、更新说明

`ModProject.cache` 里有个 `curUpdateDesc` 字段，就是每次更新的说明。以后发新版时填它。

**注意**：这是**更新日志**，会推送给订阅者，和「描述」是两个不同的字段，别拿来当描述用。

---

## 五之二、发布后还能改什么

**描述随时可改，不限次数。** 打开工坊物品页 → 右侧「编辑标题和描述」→ 保存，立即生效。

这正是本流程能成立的前提：先用编辑器发布（描述填纯文本兜底），发布后再到网页上换成 `WORKSHOP_PAGE_BBCODE.txt` 那份带图完整版。**不是一次定终身。**

| 改什么 | 在哪改 | 订阅者会重新下载吗 |
|---|---|---|
| 标题、描述、标签、可见性 | **网页上直接改** | ❌ 不会 |
| 5 张预览图 | 大概率要回编辑器重传 | ⚠️ 可能会（未实测） |
| mod 本体内容（DLL / exe / 配置） | 编辑器导出 → 上传 | ✅ 会 |

**改描述不碰文件** —— 已订阅的玩家无感，页面文字变了而已。

三个注意点：
1. 别把「更新说明」当描述用（见上一节）
2. 描述里的外链图片，图挂了描述就空了 —— 这是用 Steam 自家图床的另一个理由
3. 首次发布的描述可能过审；后续编辑通常即时生效，没变化就 Ctrl+F5 强刷

## 六、发布前检查清单

- [ ] 模组名改成「八荒智能体」
- [ ] `desc` 描述框填好（先用纯文本，别放 BBCode）
- [ ] `tags` 至少加了 `修仙` / `功能` / `AI`
- [ ] 5 张预览图都填了（尤其封面，注意**单张 ≤ 1 MB**）
- [ ] `ModAssets/config.json` **是空的**（它是运行时数据根，你填的 key 就住在这里，会被一起上传）
- [ ] 不开源（`ModProject.cache` 的 `"openCode":0`）—— 开了会把 45 MB 的 `Assembly-CSharp.dll` 一起传上去
- [ ] 导出 → 本地模组导入 → 进游戏实测通过
- [ ] 截图里的 API Key 已清空或打码
- [ ] 12 张截图已压到 ≤1600 宽（原图备份在 `F:\ .agent_loop_build\images_orig\`）
- [ ] 截图已上传到 Steam 图床、直链已填进 `WORKSHOP_PAGE_BBCODE.txt` 的 11 个占位符
- [ ] BBCode 长文粘进网页描述并预览过
