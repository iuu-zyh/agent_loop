# 队友战斗身份与生命周期修复

> 2026-11-24。基于上游 full-source 的 a5aac60，作为代码审阅和游戏回归候选。下述隔离检查不能替代 Unity/IL2CPP 实机验收。

## 问题与结果

原版地图多人 NPC 战斗中，即使没有本 Mod 队友，队友生成表也可能对共享 npcUnits 的固定 3/4/5 位置生成友军。没有识别到倒下队友时，仍可能打开附带四月重伤气运指令的剧情页。

本修复保留原版容器和原生组队、重伤流程，只追加并登记本 Mod 有效队友。原生生成返回的单位才算参战，重伤页打开前验证伤者，气运指令目标绑定到实际倒下的队友。

## 三处收敛

1. 区分追加登记与实际生成。`HasTeam` 只代表列表登记；`HasSpawned` 必须有本场原生生成返回的有效控制器。生成调用以角色 ID 限定临时绑定范围，异常路径也恢复范围。零生成不置 alTeamIn，部分生成只结算成功者，重伤要求实际参战。
2. 不再按整段命令字符串相等接管。`TeamBattleCommandCore` 识别本 Mod 的选人条件组，给对应生成、入场标志及本 Mod 重伤效果附加内部参数；执行入口移除该参数并映射真实位置。外部条件组结束生成归属范围。原生 OptionsFunction 与 CallQueue 继续执行，额外命令、延时和上下文不重新调度。
3. 重伤钩子延后挂载。世界、玩家和主地图未就绪不计次数；失败后至少间隔一秒，最多三次，成功即停止。部分安装失败撤销本次钩子，类型初始化失败立即停止并提示完整重启。退出世界撤销、清理，新世界重新登记。

## 尚未完成的实机回归

- 无队伍的原版多人 NPC 战斗：敌我双方人数、胜利后没有误伤页。
- 正常三人组队，以及决斗同意、拒绝和未表态的分支。
- 一名和多名真实队友倒下：只给真实伤者各处理一次，未倒地者与玩家不受队友重伤影响。
- 返回标题、重读存档，再次战斗：不沿用前场许可，不叠加钩子。
- 在实际 IL2CPP 命令解释器中确认内部参数会原样送达执行入口，执行前被剥离，原生队列时序保持。
