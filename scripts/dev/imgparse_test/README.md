# imgparse_test — ImageInput 路径解析回归测试

`ImageInput.SplitPaths` 决定「输入框里的哪些文本算图片路径」。它的边界不少（含空格路径、
带引号路径、正文夹路径、单行输入框、非图片后缀、不存在的文件），而且**判错的后果是静默的**
——路径没被识别 = 图没发出去，界面上看不出任何异常。所以给它配一个能一条命令跑的回归测试。

## 跑法

```bash
bash scripts/dev/imgparse_test/run.sh
```

## 原理：编译**真实源码**，不是复制副本

这些函数是纯 .NET（只用 `File`/`Path`/`StringBuilder`），但 `ImageInput.cs` 整体依赖
UnityEngine，编译不进控制台工程。`run.sh` 按**花括号配平**把函数原文抽出来拼成 `P.cs`
—— 被测代码与 `csharp/UI/ImageInput.cs` **逐字一致**，改了仓库这里立刻跟着变，
不存在"测试通过但实现已改"的漂移。

## 覆盖

| 组 | 用例 |
|---|---|
| 入口①路径文本 | 整行裸路径 / 带引号 / 中文引号 / 含空格 / 正文+盘符尾段 / 正文+引号路径 / 文件不存在 / 非图片后缀 |
| 入口②Ctrl+V 多张 | `"p1" "p2"` / 正文夹两张 / 引号内非图不误吞 |
| 边界 | 空串 / 只有空格 / 落单引号 / 多行混合 / 纯正文不误判 / `3:30` 不被当盘符 |

新增用例直接改 `Program.cs` 的 `Main`，`Case(名字, 输入, 期望正文, 期望路径[])` 一行一条。
